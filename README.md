📌 Applicant Management System 🚀
A simple C program that reads, processes, and manages job applicants using a linked list. It calculates scores, updates statuses, and outputs results to both a file and the console.

✨ Features
✔ Read Applicant Data 📂 – Loads applicants from a text file into a linked list.
✔ Calculate Scores 🎯 – Evaluates applicants based on education & experience.
✔ Update Status 🏅 – Assigns the highest-scoring applicant as "Assigned".
✔ Output Results 📄 – Saves results to a file and displays them on the console.
